# 状态空间模型

> 从故事与直觉，到理论、算法与实现

一套讲状态空间模型的书，分两本。两本覆盖同一批模型：HiPPO、LSSL、S4、S5、Mamba、Mamba-2、Mamba-3。入门版讲动机、直觉与结论，专业版讲推导、算法与实现。

序列建模的核心问题只有一个：怎样用有限的存储记住任意长的历史。这套书沿着这条线，把每一次换问法与借工具的过程讲清楚。
